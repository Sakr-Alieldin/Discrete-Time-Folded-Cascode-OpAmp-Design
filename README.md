# Discrete-Time-Folded-Cascode-OpAmp-Design
Fully differential folded-cascode opamp in 0.18 µm CMOS, closed-loop gain of 8 (TU Delft EE4520). Met all specs (SNR = 68.62 dB, settling = 54 dB in 559 ns) at 22.1 µW, FoM = 175.95 dB where FoM = -10·log10(2π·Power·T_8.6dB/SNR²) and T_8.6dB ≈ τcl (closed-loop time constant). LTspice transient, AC and noise simulations. Grade 8.5/10.
